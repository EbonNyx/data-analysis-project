# 📊 Superstore Sales Data Analysis

A data analysis project built in Python using Google Colab, exploring sales, profit, 
and customer trends from a retail superstore dataset.

## 🛠️ Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## 📁 Dataset
- **Source:** Superstore.csv
- Covers orders with fields like Sales, Profit, Region, Category, Segment, and more

## 🔍 What This Project Does

### Data Cleaning
- Removed null values and duplicates
- Parsed and formatted Order Date and Ship Date columns
- Extracted month names for time-based analysis

### Analysis & Visualizations
- **Monthly Sales Trend** – Line chart showing sales across months
- **Sales by Category** – Bar chart comparing product categories
- **Profit by Region** – Regional profit breakdown
- **Top 10 Customers** – Highest revenue-generating customers
- **Top Selling Products** – Best performing products by sales
- **Sales by Segment** – Pie chart of Consumer, Corporate, Home Office
- **Correlation Heatmap** – Relationships between numeric variables
- **Top 10 States by Sales** – Geographic sales distribution
- **Average Profit by Category** – Profitability comparison across categories

## 📌 Key Insights
- Identified the highest sales category
- Found the most profitable region
- Highlighted top customer and top selling product

## 📤 Output
Cleaned dataset exported as `cleaned_superstore_data.csv`
